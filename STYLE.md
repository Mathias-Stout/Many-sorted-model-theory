# Style

We adhere to the [Mathlib style guide](https://leanprover-community.github.io/contribute/style.html)
and [documentation guide](https://leanprover-community.github.io/contribute/doc.html). Beyond that,
we fix certain variable names for common types:

- For sorts (of a language), we will generally use letters `s`, `t`, ...
- A language should generally be called `L` or `L'` as there will
  never be too many languages around
- Families over sorts should generally be called `α`, `β`, ...
  and assignments to a model should be called `v`, `w`, ...
- Arities should be indicated by letters `σ`, `τ`, ... and
  tuples in their interpretations by `xs`, `ys`, ...
- A formula should be indicated by `φ,` `ψ`, ...
- Models should be named `M`, `N`, ...
- Theories should be written as `T`
- (Model theoretic) types should be called `p`, `q`, ...
